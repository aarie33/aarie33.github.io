## Context
Tangting Barberhome is a booking system for a barbershop business, delivered
as a Progressive Web App so customers could install it directly from the
browser without an app-store release.

## Technical challenge
Wiring offline-friendly PWA behavior on top of a CodeIgniter HMVC backend
while keeping booking-slot data consistent in real time.
