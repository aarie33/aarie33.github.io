## Context
Built for Kementerian BUMN (the Ministry of State-Owned Enterprises), this
platform tracks and reports corporate social responsibility (CSR) programs
run by Indonesia's state-owned enterprises.

## Technical challenge
Backend work on a Laravel + Vue stack handling structured CSR program data
across many contributing enterprises, with reporting as the core function
rather than an afterthought.

## Contribution
Owned the backend API layer: data modeling for CSR programs and the
reporting endpoints Vue consumed.
