## Context
Jaosing serves Jaringan Multimedia Banyuwangi, a regional multimedia
network initiative, coordinating content and operations across the
network's outlets.

## Technical challenge
First project in this run built on the Laravel + Inertia + Vue stack that
would become the default for most later work — establishing that
server-driven SPA pattern here.

## Contribution
Led the build as Dev Lead and fullstack developer, from data model through
to the Inertia-driven frontend.
