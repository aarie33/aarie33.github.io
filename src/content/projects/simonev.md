## Context
SiMonev is a monitoring and evaluation (monev) system built for Pengadilan
Agama Paniai, a religious court, to track case-handling performance against
institutional targets.

## Technical challenge
Modeling government-mandated monitoring indicators as structured data, then
surfacing them through Inertia-driven dashboards non-technical court staff
could use directly.

## Contribution
Led the build end to end as Dev Lead, from indicator data model to the
reporting UI.
